## 레거시·외부 시스템

OMS·MES·PMS·골게터 POP·에볼/썬라이즈·인쇄 5호기·위아고·로지스팟·오토콘·더존의 하위 기능은 시뮬레이터가 대신하며,
18종 I/F가 모두 동작합니다(기존). 이번에 PMS 원지입고(IF-PMS-02 입고 이벤트)를 추가했습니다.
급여관리·SECOM(근태)은 구성도상 '기존유지' 시스템이라 데모 범위 밖(➖)입니다.

## 데이터

- 기존 테이블은 바꾸지 않고 새 테이블만 추가했습니다. 배포된 DB에도 서버 재시작 시 자동 생성·적재됩니다(데모 초기화 불필요).
- 경영정보의 지난달까지 실적, 기초 미수금, 파렛트 기초 잔량, 경비 이력은 가상 데이터입니다. 이번 달은 기준 실적에 데모 중 발생한 실데이터가 더해집니다.
